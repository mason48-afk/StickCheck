Connection & detection

Why won’t my controller work?

First check power, the cable, and the connection. Try a data-capable USB cable and another port, then press a controller button with this page active. If StickCheck responds but your game does not, check the game’s controller support and input settings. If nothing responds, follow the manufacturer’s connection instructions before buying replacement hardware. More details ↗

Why is my controller connected but not detected on PC?

A paired Bluetooth device is not always exposed to a browser or game. Press a button, keep this page active, and try USB to compare. Controller remappers, drivers, browser support, and game settings can affect detection. Change one setting at a time so you know what helped. More details ↗

Why won’t my PS5 controller work on PC?

DualSense support depends on the connection and the game. Sony supports compatible USB or Bluetooth connections, but some features need game support or USB. Verify that inputs register here first, then check the game’s controller support. A successful browser test does not establish that every PC game supports all DualSense features. More details ↗

Why does my controller work with USB but not Bluetooth?

A working USB connection suggests the controller can send inputs over that path. Check charge level, pairing, device compatibility, and wireless interference. Compare the same controller in the same application on both connections before concluding that a replacement is necessary. More details ↗

Stick drift & repair verification

How do I test my controller for stick drift?

Connect the controller, verify the stick plots, place it on a stable surface, and run the resting test. Release the sticks during the three-second countdown and leave them untouched for ten seconds. Repeat the measurement, save a baseline, and compare it with your actual in-game behavior. More details ↗

What is a normal controller deadzone?

There is no universal deadzone that fits every controller and game. StickCheck’s adjustable 10% reference is a comparison aid, not a manufacturer standard. A game may use a different scale or deadzone shape. Look for repeatable unwanted movement in the games you play. More details ↗

Can I fix stick drift without replacing my controller?

Possibly, depending on the cause. Check manufacturer support, firmware and game settings first. A deadzone adjustment can hide small unwanted movement but does not repair worn hardware. Physical repairs depend on the exact model and may require soldering; check warranty coverage and repair instructions before buying parts. More details ↗

How do I check whether a stick-drift repair worked?

Use the same controller, browser, connection, axes, and reference setting to compare a new resting test with your baseline. Less measured movement is useful evidence, but also check full stick travel, return to center, every button and trigger, and real gameplay. The tool cannot certify a complete hardware repair. More details ↗

Buttons, triggers & controller layouts

How do I test Xbox or PlayStation controller buttons?

Use the button and trigger section, choose Xbox or PlayStation, and press each control. The matching tile displays its name, raw browser index and input level. A check mark records an observed press. A missing response can reflect mapping or browser limitations as well as hardware issues. More details ↗

How do I test LT/RT or L2/R2 triggers?

Slowly squeeze each trigger and watch its input meter rise, then release it and check that the reading returns. The percentages are browser-reported input levels, not measurements of physical pressure. Nintendo Switch triggers commonly report only released or pressed rather than gradual analog travel. More details ↗

Why are Nintendo Switch A and B buttons swapped on PC?

Nintendo labels differ from Xbox labels at the same physical positions. Drivers and remapping software may change the order again. Choose Nintendo Switch and press each physical button to verify the match. If the browser reports a non-standard layout, StickCheck shows raw button indices rather than assigning potentially incorrect names. More details ↗

Does a controller test work without a download?

Yes, when the browser and operating system expose your controller through the Gamepad API. StickCheck reads available inputs locally. Some controllers, extra buttons, or connection types may not be supported, and the browser can receive already-filtered inputs. More details ↗

Technical references: MDN Gamepad API, standard button mapping, and Sony’s PC controller support. Reviewed October 11, 2026.
