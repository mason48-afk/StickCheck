THE STICKCHECK FIELD GUIDE

A useful test starts
with a fair comparison.

Measure what your controller reports. Understand the limits. Save evidence you can actually use.

01. Connect and check the setup

  1. Open StickCheck directly in a current desktop browser over HTTPS. USB is a useful starting point; Bluetooth support depends on your device, operating system, and browser.
  2. Connect the controller, click the page, and press a controller button. Browsers may wait for interaction before exposing a connected gamepad.
  3. Choose the correct controller if more than one is connected. Set the connection type yourself; the browser does not reliably report it.
  4. Move each stick separately. Verify the correct plot responds. For a non-standard mapping, set the X/Y axis numbers in “Axis mapping & compatibility.”
  5. If it does not appear, try a data-capable USB cable, another port, and another supported browser. Close controller remapping software if it interferes, noting any setting changes before comparing tests.

02. Run a repeatable resting test

Set the controller on a stable surface. Start the test and release both sticks during the three-second countdown. Do not touch or bump the controller during the following ten-second sample window. Keep the tab and window active; the test cancels when they lose focus.

Run the test two or three times. A consistent result is more informative than an isolated reading. Record the connection, browser, firmware, and any remapping or deadzone settings. Keep them the same for the after-repair test. Sampling follows browser frames; this is not a measurement of USB polling rate or end-to-end input latency.

03. Read the numbers

MeasurementWhat it tells you
Center offsetDistance of the average X/Y position from the mathematical center. Opposite-direction movement can cancel in this average.
95th percentile95% of sampled radial offsets are at or below this value. Used for the reference check.
Peak offsetLargest sampled radial distance. Useful for spotting spikes, including accidental touches.
Jitter (RMS)Root-mean-square distance from the average position. A measure of movement around the reported center.

For each sample, radial offset = √(X² + Y²). The browser provides axis values between −1 and +1. We multiply distances by 100 to express a percentage of one-axis full scale. A diagonal position can therefore exceed 100%.

The reference deadzone defaults to 10% as an adjustable comparison aid. It is not a universal acceptable-drift threshold, does not change your controller settings, and is not necessarily equivalent to a game's deadzone shape or scale. “Above reference” means this measurement exceeded your selected reference—not that a repair is automatically needed.

Firmware, drivers, remappers, and operating-system processing can filter the signal before the browser receives it. A zero reading cannot establish that the physical sensor has zero drift. This tool cannot inspect internal hardware, calibrate controller firmware, or certify a repair.

04. Save before. Compare after.

Save a real resting test as your baseline and download its JSON report. The browser keeps one baseline locally, but clearing site data or using another device can remove access to it. Import your downloaded report to restore it.

After repair, repeat the test using the same physical controller and setup. StickCheck compares the device label, browser, connection type, axes, duration, and reference value. Browser device labels are not unique serial numbers, so you must confirm it is the same controller. A different firmware or deadzone can change the result even if the setup check matches.

The comparison reports the change in 95th-percentile resting offset in percentage points. Lower values indicate less resting movement under the measured conditions. Also move both sticks through their travel, release them from several directions, test every button and trigger, and try your usual games. A resting test alone cannot verify a complete repair.

Frequently asked questions

Does this work with PS5 and Xbox controllers?

It works with controllers exposed by your browser's Gamepad API. Standard-mapped DualSense and Xbox controllers commonly use axes 0/1 and 2/3. Compatibility varies by operating system, connection method, and browser. Verify movement before interpreting a result.

Can this fix my stick drift?

No. StickCheck measures reported inputs. It does not write firmware, perform hardware calibration, or change a game’s settings. Use the controller manufacturer's guidance for those steps.

What if my controller only drifts in one game?

Compare that game's controller settings and deadzone with another game. A browser test sees a different input path and may not reproduce the issue. Describe the exact conditions to a repair provider.

Why did the test cancel when I switched tabs?

Browsers can reduce or pause sampling in inactive tabs. Cancelling avoids presenting a partial ten-second test as a complete measurement.

Do you measure latency or actual polling rate?

No. Display refresh and browser scheduling are different from the controller's hardware report rate and input-to-display latency. StickCheck does not make those measurements.
